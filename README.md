## ⚡ Key Capabilities

* 🎛️ **100% Controllable via Web Dashboard:** Operate the entire pipeline, launch lead discovery scans, send 1-click pitches, manage CRM leads, trigger missed call hooks, and configure settings without ever touching terminal!
* 📞 **Missed Call Sales Strategy & Interceptor:**
  * Auto-replies to incoming WhatsApp voice calls within 2 seconds with an urgent, consultative sales message and alerts your team.
  * 1-click **"Trigger Missed Call Hook"** button to text prospects that you just tried ringing them from hotline `07228382638`.
* ⏰ **24/7 Autopilot Background Scheduler:** Toggle continuous background lead discovery (every 2h, 4h, 6h, 12h, or daily) right from the dashboard UI.
* 🐳 **Dokploy & Docker 24/7 Ready:** Pre-configured with headless Chromium, health check monitoring (`/api/health`), volume persistence, and one-click deployment for VPS and Dokploy panel (see [`DOKPLOY.md`](file:///d:/desktop/Outreach%20-%20sera/DOKPLOY.md)).
* 🤖 **Autonomous AI Sales Agent ("Kasun"):** Handles client questions, overcomes price objections, shares portfolio links (`https://seranex.lk`), qualifies leads (HOT 🔥 / WARM 🟡 / COLD ❄️), and alerts the founder via Discord & WhatsApp.

## 🛠️ Quick Start

### 1. Run Component Verification Tests
```bash
npm test
```

### 2. Launch Web Command Center Dashboard
```bash
npm run dev
# or double click start_bot.bat
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

Read the complete step-by-step Dokploy guide in [**DOKPLOY.md**](file:///d:/desktop/Outreach%20-%20sera/DOKPLOY.md).
